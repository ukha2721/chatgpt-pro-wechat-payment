## 常见问题

**付款后一直显示 Free 怎么办？**
先刷新页面、退出重新登录，确认看的是下单那个邮箱的账号，再等 5-10 分钟。超过 30 分钟仍显示 Free，去订单页提交工单让平台核查。

**充值失败会退钱吗？**
主流平台都承诺失败全额退款，PayForChat 和 GETGPT Pro 都把这条写进了页面承诺。常见的失败原因是 Session 过期，或账号还在订阅期内被系统拦下——重新获取 Session，或等到期后再下单即可。具体平台的退款规则以下单页为准。

**能开发票吗？**
部分平台可以生成 PDF Invoice（商业付款凭证），PayForChat 支持在订单页自助生成；ChongGrok 称个人和对公报销都能协助开票。但注意，这类凭证不等同于中国增值税发票，目前多数平台开不了增值税普票或专票。

**Pro 能买年费吗？**
不能。官方只按月计费，也不支持预付多个月。

**到期后怎么续费？**
这类平台一般不做自动扣款，到期前几天会发提醒邮件，到期后重新下单一次即可。如果是在官网或 App Store、Google Play 订阅的，取消和续费在对应的购买平台操作；卸载 App 不会取消订阅。
